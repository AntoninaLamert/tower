# Работа с проектом

Репозиторий: https://github.com/AntoninaLamert/tower

По просьбе владельца после завершения изменений в этой игре сохраняй их коммитом и отправляй в GitHub. Используй существующую авторизацию Git Credential Manager; не записывай токены в файлы, URL репозитория или коммиты. При ошибке отправки сохраняй локальную работу и сообщай, что синхронизация не завершена.

Игра должна запускаться локально через index.html без сервера и интернета. Matter.js хранится в vendor. Сохраняй разделение игровой логики, физики, графики и звука. Не добавляй автоматические тесты и подробные отчёты без отдельной просьбы.
